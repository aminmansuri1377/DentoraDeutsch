# تحویل نسخهٔ ۰٫۲ Dentora

## اجرای سریع

```sh
npm ci
npm run db:generate
npm run dev
```

برای تست محلی نیازی به کپی فایل env نیست. در نبود DATABASE_URL، دیتابیس آزمایشی محلی خودکار ساخته می‌شود و اطلاعات در پوشهٔ .local-database می‌مانند. اتصال اصلیِ محیط عملیاتی همچنان Supabase/PostgreSQL است.

- مسیر /anmelden: ورود و ثبت‌نام با هر ایمیل معتبر، بدون کد تأیید و بدون ارسال ایمیل.
- مسیر /panel: پنل دسکتاپ با رمز آزمایشی 1111.
- مسیر /lernen: رابط کاربران با عرض موبایل و ناوبری پایین صفحه، حتی روی دسکتاپ.
- مسیر /demo: صرفاً پیش‌نمایش با دادهٔ نمایشی مستقل.

## تغییرات اصلی

Next.js 16.4.3 پایدار و App Router حفظ شده‌اند. پنل برای هر ۴۹ مدل اسکیما ایجاد، نمایش، جست‌وجو، ویرایش و حذف دارد. فرم‌ها از اطلاعات واقعی اسکیما تولید می‌شوند و انتخاب رابطه‌ها، فهرست enum، تاریخ، عدد و کلیدهای اصلی را تشخیص می‌دهند. حذف دائمی نیاز به نوشتن LÖSCHEN دارد و تأثیر روی روابط مستقیم نشان داده می‌شود. توکن‌های ورود در خروجی پنل پوشانده می‌شوند.

مراحل، سؤال‌ها، گزینه‌های صحیح، کاربران، دوره‌ها، محصولات و سایر داده‌ها از دیتابیس خوانده می‌شوند و با پنل قابل تغییرند. سه درس کوتاه آناتومی و یک درس معرفی پلتفرم برای شروع اضافه شده‌اند. محتوای کامل مرجع کپی نشده است. متن‌ها و عنوان‌های رابط به آلمانی و لحن رایج نرم‌افزارهای آلمانی نوشته شده‌اند.

## حالت آزمایشی

رمز مشترک 1111 فقط دروازهٔ تست است و هویت ادمین را ثابت نمی‌کند. ورود با هر ایمیل نیز عمداً هویت صاحب ایمیل را بررسی نمی‌کند. فقط با داده‌های ساختگی تست شود. برای محیط واقعی ENABLE_DEMO_AUTH=false بگذارید؛ سپس ورود ایمیلی تأییدشده و نقش ADMIN لازم است. ورود سادهٔ کاربر، به‌تنهایی اجازهٔ ورود به پنل نمی‌دهد.

## محدودیت‌های باقی‌مانده

CRUD همهٔ جدول‌ها به معنی تکمیل همهٔ گردش‌های بیرونی نیست: آپلود رسانه، بازپرداخت واقعی، تأیید دانشجویی، ارسال خودکار اعلان و حذف/خروجی جامع حساب هنوز کار تکمیلی دارند. تغییر وضعیت سفارش در جدول، پولی را در Stripe برنمی‌گرداند. اتصال واقعی Supabase/Vercel و آزمون کامل مرورگری هنوز تأیید نشده‌اند. جزئیات در FEATURE-COVERAGE.md و VERIFICATION.md آمده‌اند.
