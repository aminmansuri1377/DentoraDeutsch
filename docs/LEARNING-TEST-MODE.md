# حالت تست محدودیت‌های یادگیری

برای غیرفعال‌کردن سهمیه روزانه درس و محدودیت قلب، در فایل واقعی .env و متغیرهای محیطی Vercel تنظیم کنید:

DISABLE_LEARNING_LIMITS=true

در Vercel محیط Production (و در صورت نیاز Preview) را انتخاب و سپس مجدداً Deploy کنید.
برای اجرای محلی، سرور npm run dev را متوقف و دوباره اجرا کنید.

در این حالت تعداد شروع درس محدود نیست؛ صفر بودن قلب مانع شروع یا پاسخ نیست و پاسخ اشتباه قلب کم نمی‌کند.
پاسخ اشتباه همچنان اشتباه ثبت می‌شود و به مرورها اضافه می‌شود.
ورود، دسترسی دوره، ترتیب درس‌ها، انقضای جلسه، کنترل مالکیت و جلوگیری از امتیاز تکراری تغییری نمی‌کنند.
قلب نمایش‌داده‌شده همچنان مقدار واقعی حساب است؛ امتیاز و پیشرفت تست‌ها ذخیره می‌شود.

برای بازگرداندن محدودیت‌ها، مقدار را false کنید یا متغیر را حذف کنید و دوباره Deploy کنید.
حالت پیش‌فرض محدودیت‌دار است؛ این تنظیم مستقل از NODE_ENV و ENABLE_DEMO_AUTH عمل می‌کند.
سابقه تلاش‌ها حذف نمی‌شود؛ پس پس از فعال‌کردن مجدد، تلاش‌های ۲۴ ساعت گذشته در سهمیه حساب می‌شوند.
نیازی به migration یا seed نیست.
